## [1.0.0] - 2024-XX-XX

### Hinzugefügt
- RegEx Builder mit visueller Pattern-Erstellung
- RegEx Analyzer zum Verstehen bestehender Patterns
- Vorlagen für häufige Anwendungsfälle (E-Mail, IBAN, Telefonnummern, etc.)
- Live-Vorschau und Test-Funktion
- Zweisprachige Unterstützung (Deutsch/Englisch)
- Dark Mode Unterstützung
- Barrierefreie Benutzeroberfläche (WCAG 2.1 AA)
- Responsive Design für alle Geräte
- Anpassbare Schriftgrößen
- Offline-Funktionalität
- LocalStorage für Einstellungen

### Features
- **Builder**: Visuelle Erstellung von RegEx-Patterns durch Bausteine
- **Analyzer**: Zerlegung und Erklärung bestehender RegEx-Patterns
- **Vorlagen**: Vorgefertigte Patterns für schnellen Einstieg
- **Bausteine**: Verschiedene Typen von Pattern-Komponenten
- **Live-Test**: Sofortiges Testen von Patterns
- **Export**: Einfaches Kopieren der generierten Patterns

### Technisch
- Single-Page-Application in einer HTML-Datei
- Vanilla JavaScript ohne externe Abhängigkeiten
- CSS-Variablen für Theming
- Event-Delegation für Performance
- Modularer, wartbarer Code
